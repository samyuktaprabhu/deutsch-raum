# Deutschraum

**Your personal German-learning classroom — from A2 refresh to B1 confidence.**

Deutschraum is a lightweight, browser-based companion for a structured German study plan. It is designed to help learners revise A2 foundations, work through *Netzwerk neu B1*, and prepare for the telc B1 examination.

## What’s included

- A responsive classroom homepage
- A 32-session weekday learning roadmap, from December 2026 to January 2027
- A2 refresher sessions covering sentence structure, cases, prepositions and tenses
- B1 study sessions organised around 12 textbook chapters
- Final telc B1 preparation sessions for grammar, reading, listening, writing and speaking
- Filters for all sessions, A2, B1 and completed sessions
- Completion tracking with progress saved in the browser using `localStorage`
- A suggested 90-minute evening study routine

## Open the classroom

Once GitHub Pages is enabled for this repository, visit:

**https://samyuktaprabhu.github.io/deutsche-raum/**

To enable it, open **Settings → Pages** in the GitHub repository, choose **Deploy from a branch**, select the `master` branch and `/(root)`, then save.

## Run locally

No build tools or dependencies are required.

1. Clone this repository:
   ```bash
   git clone https://github.com/samyuktaprabhu/deutsche-raum.git
   ```
2. Open the repository folder.
3. Open `index.html` in your browser.

## Course approach

The study plan follows three stages:

1. **A2 refresh** — revisit essential grammar and vocabulary.
2. **B1 development** — use the corresponding sections and exercises in *Netzwerk neu B1*.
3. **telc B1 preparation** — practise the exam skills: reading, Sprachbausteine, listening, writing and speaking.

A suggested 90-minute session is:

| Activity | Time |
|---|---:|
| Vocabulary revision | 10 min |
| Grammar focus | 20 min |
| Textbook exercises | 20 min |
| Reading or listening | 15 min |
| Speaking or writing | 15 min |
| Review and corrections | 10 min |

## Progress data

Completed sessions are stored in the browser's local storage on the device and browser where the classroom is used. Progress is not currently synchronised between devices.

## Textbook and content notice

Deutschraum is an independent learning companion. It is not affiliated with or endorsed by Klett. The *Netzwerk neu B1* textbook, its exercises and audio materials are not included; use your own licensed copy or the publisher's platform for those materials. Chapter sessions are intended to be matched to the contents of your own edition.

## Current scope

The current version is a static HTML classroom and course tracker. Interactive lesson content, automated exercise correction, accounts and cross-device progress synchronisation are not implemented yet.
